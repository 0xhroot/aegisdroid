## Before Asking for Help

1. **Read the README** — Most questions are answered there
2. **Check the FAQ** — See if your question has been asked before
3. **Search existing issues** — Your issue may already be reported
4. **Check troubleshooting** — Common problems and solutions
5. **Reproduce the issue** — Make sure you can reliably reproduce it

## Bug Reports

When reporting a bug, include:

- **AegisDroid version**: `aegis --version` or `python -c "import aegisdroid; print(aegisdroid.__version__)"`
- **Python version**: `python --version`
- **OS**: Distribution and version
- **ADB version**: `adb version`
- **Steps to reproduce**: Clear, minimal steps
- **Expected behavior**: What you expected to happen
- **Actual behavior**: What actually happened
- **Logs**: Relevant output or error messages

## Feature Requests

We welcome feature requests! Please:

1. Describe the problem the feature solves
2. Explain your use case
3. If possible, sketch the desired interface
4. Check if a similar feature already exists

## Discussions

Use GitHub Discussions for:

- **Q&A**: Ask questions about usage
- **Ideas**: Propose new features or improvements
- **Show and Tell**: Share how you use AegisDroid
- **General**: Community conversation
